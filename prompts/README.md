## Dify への適用手順

1. 適用したいバージョンのファイルをテキストエディタで開く
2. 全文をコピー
3. Dify の該当アプリ → 「プロンプト編集」 → システムプロンプト欄に貼り付け
4. 保存・公開

**注意:** `{{#context#}}` はDifyのテンプレート変数で、RAG検索結果が自動挿入される。手動で変更しないこと。

## バージョン命名規則

```
v<番号>_<特徴>.md
```

例:
- `v3_emotion_tuning.md` — 感情モデル調整版
- `v4_shorter_response.md` — 回答を簡潔にする版
