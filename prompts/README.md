## 注意

現在の実際のプロンプトは **`src/rag/prompts.py`** の `ANSWER_SYSTEM_PROMPT` を参照すること。
ここにあるバージョンファイルは履歴・参考用である。

## バージョン命名規則

```
v<番号>_<特徴>.md
```

例:
- `v3_emotion_tuning.md` — 感情モデル調整版
- `v4_shorter_response.md` — 回答を簡潔にする版
