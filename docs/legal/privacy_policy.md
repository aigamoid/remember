# プライバシーポリシー

{{サービス名}}（以下「本サービス」）は、Discord 上で動作する RAG チャットボットです。
本サービスの提供にあたり取得する情報の取り扱いについて、以下のとおり定めます。

最終更新日: {{制定日 例: 2026-06-17}}
運営者: {{運営者表記（ハンドルネーム等）}}

## 1. 取得する情報

本サービスは、サーバー管理者が**明示的に許可（opt-in）したチャンネル**に限り、以下を取得・保存します。

- メッセージ本文
- 投稿者の表示名・ユーザーID
- 投稿日時（タイムスタンプ）
- チャンネル名・チャンネルID・サーバー（ギルド）ID
- 添付ファイルのURL・ファイル名（ファイル実体は原則保存しません）
- 本サービスへの質問内容、および質問したユーザーのID（回答・利用量集計のため）

> 管理者が許可していないチャンネルのメッセージは取得しません。
> DM（ダイレクトメッセージ）は取得対象外です。

## 2. 利用目的

- 過去ログを検索可能にするためのインデックス（ベクトル化）作成
- 質問に対する回答の生成
- 不具合調査・品質改善、および利用量・コストの把握

## 3. 第三者への提供・外部送信

本サービスは回答生成のため、取得した情報の一部を以下の外部サービスへ送信します。

| 送信先 | 目的 | 送信される主な情報 |
|---|---|---|
| OpenAI | テキストの埋め込み（ベクトル化） | チャンク化したメッセージ本文・質問文 |
| OpenRouter（経由の各LLM） | 回答・クエリ生成 | 質問文・検索で関連したメッセージ本文 |
| Google Cloud Platform | データの保管・サーバー稼働（リージョン: 東京） | 上記の保存データ全般 |
| Discord | メッセージの取得・応答 | Discord APIの仕様に準じる |

上記以外の第三者へ、本人の同意なく個人情報を提供することはありません（法令に基づく場合を除く）。
各外部サービスでの取り扱いは、それぞれの提供事業者のプライバシーポリシーに従います。

## 4. 保存期間とデータの削除

- 保存したデータは、本サービスが当該サーバーに在籍する間、保持されます。
- **本サービス（Bot）をサーバーから退出させると、そのサーバーのデータはすべて削除されます。**
- 管理者が特定チャンネルの許可を取り消す（deny）と、そのチャンネルのデータは削除されます。
- その他の削除のご希望は、第8項の連絡先までご連絡ください。

## 5. 安全管理措置

- データは外部に公開されたポートを持たない環境で保管し、管理アクセスは限定された経路に制限しています。
- APIキー等の機密情報はシークレット管理サービスで保護しています。
- サーバー（ギルド）ごとにデータを分離し、他サーバーの回答に混在しない設計としています。

## 6. 未成年の利用

本サービスは Discord 上で動作します。Discord の利用規約（13歳以上等の年齢要件）に従ってご利用ください。

## 7. 本ポリシーの変更

サポート窓口等で告知します。改定後の利用をもって、変更に同意したものとみなします。
