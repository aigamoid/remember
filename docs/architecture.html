実行シーケンス（Phase 2 — chunker.py）

sequenceDiagram participant M as chunker.py participant CHR as src/chunker.py participant DB as SQLite (messages.db) M->>DB: init_db() — chunk_index テーブル確認 M->>CHR: run_chunker(conn, cfg, run_id) CHR->>DB: SELECT DISTINCT channel_id FROM messages loop 各チャンネル（32チャンネル） CHR->>DB: SELECT id, author_name, content, timestamp, has_attachment
WHERE channel_id = ? ORDER BY timestamp ASC DB-->>CHR: メッセージ一覧 loop 各メッセージ（アンカー候補） CHR->>CHR: len(content) < 4 AND NOT has_attachment → skip CHR->>CHR: window = rows[i-2 : i+3] CHR->>CHR: chunk_text = _build_chunk_text(window)
[2024-05-03 21:13] UserA: ... CHR->>CHR: chunk_id = MD5(anchor_msg_id:2:2) CHR->>DB: INSERT OR IGNORE INTO chunk_index
(chunk_id, anchor_msg_id, channel_id, chunk_text) end CHR->>DB: conn.commit() CHR->>M: channel count end M->>DB: count_chunks(status="pending") M->>DB: log_run(run_id, "chunk", "success", "完了: N件") M->>M: print 完了メッセージ
window_before=2 / window_after=2 / min_content_length=4（config.yml）
INSERT OR IGNORE で冪等性確保（再実行しても chunk_index の件数は変わらない）
